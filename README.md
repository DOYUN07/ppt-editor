# PPT 편집기

색만 고르면 나머지 색과 양식을 알아서 맞춰 주고, 내용을 입력하면 **편집 가능한 PowerPoint(.pptx)** 를 만들어 주는 Windows용 로컬 편집기입니다.

브라우저에서 편집하고, 실제 파일은 PC에 설치된 PowerPoint가 만듭니다. 테마 색·글꼴, 슬라이드 마스터, 구역, 발표자 노트, 네이티브 차트가 들어간 구조화된 덱이라 PowerPoint에서 그대로 고쳐 쓰기 좋습니다.

## 주요 기능

- **색 자동 조합**: 메인·강조 색만 고르면 12색 테마를 만들고, 글자 대비가 부족하면 자동으로 보정
- **양식 추천**: 누를 때마다 표지 구성, 장식·사진 위치(좌우 반전), 제목 정렬, 섹션 라벨, 카드·단계 배치, 도형 모양이 함께 바뀜 (최근 양식과 겹치지 않게)
- **로고**: PNG·SVG·JPG 업로드. 투명 PNG는 어두운 배경용 흰색 로고를 자동 생성
- **사진**: 버튼으로 첨부하거나 미리보기에 끌어다 놓기. 영역에 맞게 자동 크롭
- **슬라이드 12종**: 표지, 목차, 섹션, 글머리표+이미지, 사진, 카드, 숫자 지표, 차트(막대·꺾은선·원형), 단계·로드맵, 비교, 표, 마무리
- **기존 PPT 가져오기**: .pptx를 열어서
  - **원본 디자인 유지 수정** — 미리보기에서 영역을 눌러 글자·사진·표·노트를 고치고, 슬라이드 삭제, 내 색 조합(테마 색·글꼴) 적용. 원본은 그대로 두고 새 파일로 저장
  - **새 양식으로 다시 만들기** — 목차·지표·단계·비교·카드·차트·표를 알아보고 편집기 슬라이드로 옮긴 뒤 새 디자인으로 생성
- **실시간 미리보기**, 색·로고 조합 저장, 프로젝트 저장/불러오기, `.potx` 서식 파일 저장

## 요구 사항

- Windows 10 / 11
- Microsoft PowerPoint 데스크톱 버전 (Microsoft 365 또는 Office 2016 이상)
- 권장 글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (없으면 다른 설치된 글꼴을 선택)

## 설치

1. 이 저장소를 내려받아요: **Code → Download ZIP**
2. ZIP 파일 우클릭 → **속성** → 아래쪽 **"차단 해제"** 체크 → 확인 (인터넷에서 받은 스크립트 경고 방지)
3. 압축을 풀고 **`설치.bat`** 더블클릭
4. 바탕화면의 **"PPT 편집기"** 아이콘으로 실행

설치하지 않고 바로 써 보려면 `PPT편집기 실행.bat`을 더블클릭해도 됩니다.

## 사용 방법

자세한 내용은 [`사용설명서.txt`](사용설명서.txt)를 참고하세요.

1. 왼쪽에서 색·글꼴·로고를 고르고 **[다른 양식 추천]** 으로 마음에 드는 양식을 찾기
2. 오른쪽에서 슬라이드를 추가하고 내용 입력 (목록은 `제목 | 설명` 처럼 `|` 로 구분)
3. **[PPT 만들기]** → 1~2분 뒤 `문서\PPT Editor` 폴더에 저장

기존 파일을 고치려면 **[PPT 가져오기]** 를 누르거나 .pptx를 화면에 끌어다 놓으세요.

## 구조

```
app/index.html            편집기 화면 (미리보기 렌더러 포함)
server.ps1                로컬 서버 (http://localhost:8765, 이 PC에서만 접속 가능)
engine/scripts/build.ps1  PowerPoint를 COM으로 구동해 .pptx 생성
engine/scripts/import.ps1 기존 .pptx 분석 (도형·글자·사진·표·차트 데이터, 슬라이드 미리보기)
engine/scripts/apply.ps1  원본 디자인을 유지한 채 수정 사항 적용 후 새 파일로 저장
engine/layouts.json       양식 프리셋
install.ps1, 설치.bat     사용자 폴더에 설치하고 바로가기 생성
```

`build.ps1`은 편집기 없이도 쓸 수 있어요.

```powershell
powershell -ExecutionPolicy Bypass -File engine\scripts\build.ps1 -Spec spec.json -Style style.json -Brand brand.json -Out deck.pptx -PngDir png
```

## 데이터 저장 위치

| 항목 | 위치 |
|---|---|
| 만든 PPT | `문서\PPT Editor` |
| 색·로고 조합, 프로젝트, 올린 사진, 양식 기록 | `%APPDATA%\PPT-Editor` |

편집기는 내 PC에서만 동작하며 내용을 외부로 보내지 않습니다.
