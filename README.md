# PPT 편집기

미리캔버스처럼 캔버스에서 자유롭게 편집하면서, 색만 고르면 양식은 알아서 맞춰 주는 **Windows용 PowerPoint 편집기**입니다.
브라우저에서 편집하고, 실제 파일은 PC의 PowerPoint가 만들기 때문에 결과물은 **그대로 편집 가능한 .pptx**입니다
(테마 색·글꼴, 실제 표·차트, 애니메이션, 화면 전환, 발표자 노트 포함).

## 주요 기능

**디자인 자동화**
- 메인·강조 색만 고르면 12색 테마를 만들고, 글자 대비가 부족하면 자동 보정
- 슬라이드 모양 14종(표지, 목차, 섹션, 글머리표, 사진, 카드, 숫자 지표, 차트, 단계, 비교, 표, 마무리 등)
- **다른 양식 추천**: 표지 구성, 좌우 배치, 제목 정렬, 섹션 라벨, 카드·단계 배치, 도형 모양이 함께 바뀜
  (직접 쓴 글자·서식·추가한 요소는 유지)
- 색·로고 조합 저장, 투명 PNG 로고는 어두운 배경용 흰색 로고 자동 생성

**자유 편집 캔버스**
- 선택·이동·크기 조절·회전, 다중 선택, 정렬 안내선(스냅), 잠금, 앞뒤 순서, 맞춤·간격 똑같이
- 도형 30종, 선·화살표, 아이콘 60여 개, 글상자 프리셋, 사진(끌어다 놓기·붙여넣기·모양으로 자르기)
- 사진 배경 지우기: 자동(가장자리에서 이어진 배경), 클릭 지우기, 지우개·복원 붓 — 브라우저 안에서 처리, 투명 PNG로 저장
- 표(행·열 추가), 차트 9종(세로·가로·누적 막대, 꺾은선, 영역, 원형, 도넛, 방사형)
- 글자 직접 편집: 글꼴·크기·굵게·기울임·밑줄·취소선·색·정렬·글머리 기호·번호·들여쓰기·줄 간격·링크
- 애니메이션 14종, 화면 전환 36종, 배경 색·사진, 슬라이드 숨기기, 발표자 노트
- 실행 취소/다시 실행, 복사·붙여넣기·복제 단축키, 발표 미리보기(F5)

**기존 PPT 가져오기**
- **자유 편집으로 가져오기** — 글상자·도형·사진·표·차트를 캔버스 요소로 변환(배경·마스터 그림은 배경 이미지로).
  글꼴(한글 글꼴 이름 자동 인식, PC에 없는 글꼴 알림·대체), 글머리 기호 모양, 줄·문단 간격, 차트 색·숫자 형식까지 유지
- **원본 그대로 두고 고치기** — 원본 디자인 유지, 글자·사진·표·노트 수정, 슬라이드 삭제, 테마 색 교체
- **새 양식으로 다시 만들기** — 내용을 뽑아 목차·카드·지표·단계 등 편집기 양식으로 재구성

**내보내기**: .pptx, PDF, 서식 파일(.potx)

## 요구 사항

- Windows 10 / 11
- Microsoft PowerPoint 데스크톱 버전 (Microsoft 365 또는 Office 2016 이상)
- 권장 글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (없으면 다른 설치된 글꼴을 선택)

## 설치

1. 이 저장소를 내려받아요: **Code → Download ZIP**
2. ZIP 파일 우클릭 → **속성** → 아래쪽 **"차단 해제"** 체크 → 확인 (인터넷에서 받은 스크립트 경고 방지)
3. 압축을 풀고 **`설치.bat`** 더블클릭
4. 바탕화면의 **"PPT 편집기"** 아이콘으로 실행

설치하지 않고 바로 써 보려면 `PPT편집기 실행.bat`을 더블클릭해도 됩니다. 자세한 사용법은 [`사용설명서.txt`](사용설명서.txt)를 참고하세요.

## 구조

```
app/index.html              편집기 화면
app/js/model.js             데이터 모델, 색 계산, 슬라이드 양식(요소 생성), 엔진용 문서 변환
app/js/view.js              요소 렌더링 (캔버스·썸네일·발표 미리보기 공용)
app/js/app.js               캔버스 편집, 도구 막대, 패널, 내보내기, 발표 모드
app/js/import.js            기존 PPT 가져오기 (세 가지 방식)
app/js/bgremove.js          사진 배경 지우기
app/js/shapes.js, icons.js  도형·아이콘 라이브러리
server.ps1                  로컬 서버 (http://localhost:8765, 이 PC에서만 접속 가능)
engine/scripts/render.ps1   편집기가 계산한 요소를 PowerPoint(COM)로 그려 .pptx/.pdf 생성
engine/scripts/import.ps1   기존 .pptx 분석 (도형·글자 서식·사진·표·차트·배경)
engine/scripts/apply.ps1    원본 디자인을 유지한 채 수정 사항 적용
engine/scripts/build.ps1    내용(JSON)만으로 덱을 만드는 스크립트 생성기 (편집기 없이 사용)
install.ps1, 설치.bat       사용자 폴더에 설치하고 바로가기 생성
```

배치는 편집기(`model.js`)가 한 번만 계산하고 엔진은 그 결과를 그대로 그리기 때문에, 화면과 결과 파일이 같게 나옵니다.

## 데이터 저장 위치

| 항목 | 위치 |
|---|---|
| 만든 PPT | `문서\PPT Editor` |
| 색·로고 조합, 프로젝트, 올린 사진, 양식 기록 | `%APPDATA%\PPT-Editor` |

편집기는 내 PC에서만 동작하며 내용을 외부로 보내지 않습니다.
