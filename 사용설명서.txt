PPT 편집기 사용설명서
=====================

■ 필요한 것
- Windows 10/11
- Microsoft PowerPoint 데스크톱 버전 (Microsoft 365 또는 Office 2016 이상)
- 권장 글꼴: Pretendard (없으면 맑은 고딕 등 다른 글꼴을 골라 쓰면 돼요)

■ 설치
1. 받은 압축 파일을 풀어요.
2. 폴더 안의 "설치.bat"을 더블클릭해요.
   (Windows가 "PC 보호" 창을 띄우면 [추가 정보] → [실행]을 누르세요.)
3. 바탕화면에 "PPT 편집기" 아이콘이 생겨요.

■ 실행
- 바탕화면의 "PPT 편집기"를 더블클릭하면 브라우저에 편집기가 열려요.
- 작업 표시줄에 작은 "PPT Editor" 창이 함께 떠요. 이 창을 닫으면 편집기가 꺼져요.
- 편집기는 내 PC 안에서만 동작하고, 인터넷으로 내용을 보내지 않아요.

■ 화면 구성
- 왼쪽 탭
  · 디자인: 메인·강조 색, 글꼴, 로고, 양식(표지·배치·도형 모양). [다른 양식 추천]으로 전체 디자인을 바꿔요.
  · 템플릿: 슬라이드 모양 14종(표지, 목차, 카드, 지표, 차트, 단계, 비교, 표, 사진 등)을 추가하거나 현재 슬라이드를 바꿔요.
  · 요소: 도형 30종, 선·화살표, 아이콘 60여 개
  · 텍스트: 제목·부제목·본문·캡션·강조 숫자·인용구·목록
  · 사진: 사진 올리기, 올린 사진 모음
  · 표·차트: 표(칸 수 고르기), 차트 8종
  · 배경: 배경 색·사진
- 가운데 캔버스: 요소를 눌러 선택하고, 끌어서 옮기고, 모서리로 크기 조절, 위쪽 동그라미로 회전해요.
- 오른쪽 패널: 선택한 요소의 위치·크기·투명도·그림자·애니메이션, 표·차트 데이터.
  아무것도 선택하지 않으면 슬라이드 설정(내용, 배경, 화면 전환, 숨기기, 발표자 노트).
- 아래쪽: 슬라이드 목록. 끌어서 순서를 바꿔요.

■ 자주 쓰는 조작
- 글자 고치기: 글상자를 더블클릭(또는 선택 후 Enter). 위쪽 막대로 글꼴·크기·굵게·색·정렬·글머리 기호.
  Shift+Enter 줄바꿈, Tab 들여쓰기, Esc 편집 끝내기.
- 여러 개 선택: Shift+클릭 또는 빈 곳에서 끌어서 범위 선택
- 복사 Ctrl+C / 붙여넣기 Ctrl+V / 복제 Ctrl+D / 삭제 Delete / 실행 취소 Ctrl+Z / 다시 실행 Ctrl+Y
- 미세 이동: 방향키(Shift와 함께 10칸)
- 확대/축소: Ctrl+마우스 휠, 오른쪽 아래 버튼
- 사진: 캔버스에 사진 파일을 끌어다 놓거나 Ctrl+V. 사진 요소를 더블클릭하면 바꿀 수 있어요.
- 사진 배경 지우기: 사진을 고르고 위쪽 [배경 지우기]를 눌러요.
  [자동으로 배경 지우기] → 남은 부분은 "클릭 지우기"로 누르거나 지우개·복원 붓으로 다듬은 뒤 [적용].
  배경이 단색이거나 단순한 사진(제품, 로고, 증명사진 등)에서 잘 돼요. 원래 사진은 사진 모음에 그대로 남아요.
- 정렬·순서: 요소를 고르고 위쪽 [정렬·순서]에서 맨 앞으로/뒤로, 맞춤, 간격 똑같이.
- 발표 미리보기: [▶ 발표] 또는 F5 (애니메이션·화면 전환 미리 보기)

■ 양식과 직접 수정
- 템플릿 슬라이드는 내용만 입력하면 배치가 자동으로 잡혀요. 글자는 캔버스에서 바로 고쳐도 돼요.
- [다른 양식 추천]을 누르면 배치가 바뀌어요. 이때 직접 옮긴 위치는 초기화되지만
  글자·색·서식과 직접 추가한 요소는 그대로예요.
- 한 슬라이드를 완전히 자유롭게 고치려면 슬라이드 설정에서 "자유 슬라이드"로 바꾸세요.

■ 내 양식 (자주 쓰는 디자인 저장)
- 마음에 드는 슬라이드(가져온 PPT 슬라이드 포함)를 열고, 왼쪽 [템플릿] 탭 맨 위의 [＋ 이 슬라이드 저장]
  또는 슬라이드 설정 아래의 [★ 내 양식으로 저장]을 눌러요.
- 저장한 양식은 [템플릿] 탭 맨 위 "내 양식"에 모여요. 누르면 새 슬라이드로 추가되고,
  "현재 슬라이드 바꾸기"를 고른 상태면 지금 슬라이드를 그 양식으로 바꿔요.
- 양식의 색은 그때그때 고른 색 조합을 따라가요. 같은 디자인을 다른 색으로도 쓸 수 있어요.
- 양식 오른쪽 위 ✕로 삭제해요.

■ PPT 만들기
- [PPT 만들기]를 누르면 1~3분 뒤 완성돼요. ▾ 메뉴에서 PDF·서식 파일(.potx)도 함께 저장할 수 있어요.
- 결과물은 일반 PowerPoint 파일이라 PowerPoint에서 그대로 편집할 수 있어요
  (테마 색·글꼴, 실제 표·차트, 애니메이션, 화면 전환, 발표자 노트 포함).

■ 기존 PPT 가져오기
- 위쪽 [PPT 가져오기]를 누르거나 .pptx 파일을 편집기 화면에 끌어다 놓고, 세 가지 중에 골라요.
  1) 자유 편집으로 가져오기: 모든 글상자·도형·사진·표·차트를 캔버스 요소로 바꿔요.
     슬라이드 배경과 마스터 그림은 배경 이미지로 들어가요.
     원호·물방울·자유형 같은 도형도 원래 모양 그대로 "도형"으로 들어와서 색·크기를 바꿀 수 있어요.
     그라데이션·그림자·네온·부드러운 가장자리 효과도 유지돼요(오른쪽 패널에서 없앨 수 있어요).
     3차원 효과·반사·무늬/그림 채우기처럼 편집기가 그릴 수 없는 것만 그림으로 들어가요.
  2) 원본 그대로 두고 고치기: 원본 디자인을 그대로 둔 채 글자·사진·표·노트만 바꾸고 슬라이드를 지워요.
     "내 색 조합 적용"을 켜면 원본의 테마 색·글꼴을 바꿔요.
  3) 새 양식으로 다시 만들기: 내용만 뽑아서 편집기 양식(목차·카드·지표·단계 등)으로 새로 디자인해요.
- 자유 편집으로 가져오면 색·글꼴을 어떻게 할지 물어봐요.
  · 원본 색 그대로 + 색 조합에 연결 (추천): 원본과 똑같이 보이고, 원본 색은 '가져온 색: 파일 이름' 색 조합으로
    저장돼요. 디자인 탭에서 다른 색 조합을 고르면 가져온 슬라이드 색도 한 번에 바뀌어요.
  · 지금 내 색 조합·글꼴로 바꾸기: 배치는 원본 그대로 두고 색과 제목·본문 글꼴을 바로 바꿔요.
  · 바꾸지 않기: 원본 색을 고정해요.
- 원본에 쓰인 글꼴이 이 PC에 없으면 같은 창에서 대신 쓸 글꼴을 고를 수 있어요. 글꼴을 설치한 뒤 다시
  가져오면 원본과 같게 보여요. (글꼴이 없으면 PowerPoint로 열어도 줄바꿈이 달라져요.)
- 암호가 걸린 파일은 가져올 수 없어요.

■ 저장 위치
- 만든 PPT: 문서\PPT Editor
- 색 조합·프로젝트·올린 사진: %APPDATA%\PPT-Editor
- 작업 중인 내용은 브라우저에 자동 저장돼요. 오래 보관하려면 위쪽 [저장]을 누르세요.

■ 문제가 생기면
- "만들지 못했어요"가 뜨면 열려 있는 PowerPoint의 대화상자(저장 여부 등)를 닫고 다시 시도해요.
- 화면에 나온 오류 기록을 담당자에게 보내 주세요.
